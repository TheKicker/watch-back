    What to put in each tag

    The schema below is the OSM community's, documented on the ALPR wiki page. Stick to it and your edits stay compatible with every downstream consumer.

    KeyValueNotes
    man_madesurveillanceRequired. Marks it as a camera.
    surveillance:typeALPRRequired. What makes it a plate reader.
    surveillancepublicWatches a public space.
    surveillance:zonetrafficOr parking / entrance.
    camera:typefixedALPRs are almost always fixed.
    direction105Degrees it faces. Dual-head unit: 105;285.
    manufacturerFlock SafetyRead it off the housing if you can.
    operatorCity of SteubenvilleWho runs it — the most-missing tag locally.
    camera:mountpoleOr wall / mast.
    Safety and legality. Photographing infrastructure from a public place is legal in the US, but use judgment: don't trespass, don't obstruct traffic, and don't interfere with any device. Observing and recording a location is the whole job — nothing here asks you to touch anything.

    Adding one that isn't mapped yet

    1. Make a free OpenStreetMap account.
    2. Open the iD editor at the location.
    3. Drop a Point on the pole, then paste the tags above in the text view.
    4. Set direction to the way the lens faces — this is what draws the cone on our map.
    5. Save with a clear comment like Add ALPR on SR-7 at Lovers Lane.

    It reaches this map within six hours (our Overpass cache window) and DeFlock on their own refresh. Prefer a guided flow? The DeFlock app walks you through the same edit.

    Running this site yourself

    Everything above works with no API key and no server. The only keyed piece is the ODOT camera catalog, which is baked at build time so the key never reaches a browser:

    1. Register a free key at publicapi.ohgo.com — ODOT data is public domain.
    2. Add it as a repo secret named OHGO_API_KEY.
    3. Run the Update ODOT camera catalog workflow (or wait for the nightly run).

    It commits a refreshed data/cameras.json. GitHub Actions is free with unlimited minutes on public repositories, and the site itself calls no serverless functions at all — camera images and Overpass are both fetched straight from the browser.
